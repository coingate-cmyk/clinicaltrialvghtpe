clinicaltrialvghtpe v4.3.0 public trials portal

Purpose:
- Add an independent public clinical trial query page for patients/families.
- Keep it separate from the internal password-protected trial management page.
- Let the existing admin page publish sanitized public data anytime.

New / changed files:
- index.html: adds admin-only buttons: 發布公開查詢, 下載公開JSON, 公開頁預覽.
- 404.html: same app fallback update.
- public-trials.html: independent public query page.
- public_trials.json: fallback sanitized public data; live page prefers Firebase public/clinical-trials if available.
- PUBLIC_TRIALS_v4_3_0_QA.csv: QA checks.

Public data source:
- Main live source: Firestore doc public/clinical-trials written by admin button 發布公開查詢.
- Fallback source: public_trials.json in repo root.

Public fields:
- code, studyTitle, phase
- publicStatus/statusClass
- publicPhysicians: only 洪逸平醫師, 陳明晃醫師, 姜乃榕醫師
- cancerTypes + treatment lines
- inclusion/exclusion criteria

Excluded from public dataset:
- internal contact fields, private phone-like strings, messaging IDs, patient/subject data, sponsor/contract/internal comments, accrual numbers.

Current fallback public trial count: 41
QA: 22/22 pass

Deployment:
1. Upload index.html and 404.html to repo root to update the private admin page.
2. Upload public-trials.html and public_trials.json to repo root.
3. Public URL: https://coingate-cmyk.github.io/clinicaltrialvghtpe/public-trials.html
4. To update public data later: open the existing admin page, log in as admin, click 發布公開查詢. No GitHub Actions required.
5. If Firebase public read is blocked by rules, click 下載公開JSON and manually upload the generated public_trials.json as fallback.
