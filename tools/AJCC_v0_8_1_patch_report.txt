AJCC quick staging v0.8.1 gastric clinical + exact matcher fix

Fixed two issues:
1) AJCC8 Stomach clinical cTNM had only sentinel rows in v0.7; full cTNM rows are now added.
2) The matcher was too permissive: same-letter categories could match each other (e.g., M0 vs M1, AJCC7 vs AJCC8). The JS token matcher now allows only:
   - exact match
   - rule parent to selected subcategory (e.g., N3 matches N3a/N3b)
   - selected parent to rule subcategory when appropriate
   It no longer matches by broad letter family.
