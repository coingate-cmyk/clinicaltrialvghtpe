結果摘要

預設邏輯：mg/m² 預設使用 Mosteller actual-weight BSA；若切換為「直接輸入 BSA」，mg/m² 與相關 BSA-based 計算改用手動 BSA。mg/kg 仍使用 actual BW。AdjBW / AdjBW-BSA 只有在你主動選擇時才套用。Dose reduction 先乘比例，再套 max dose，最後才做 rounding。
肥胖病人：此工具把 actual body weight / actual BSA 放在預設值。ASCO 指引建議肥胖成人接受細胞毒性化療時仍使用 full weight-based dosing；若 protocol 指定 IBW / AdjBW / dose cap，再手動切換。
這不是處方驗證器：不會檢查 regimen、cycle/day、腎肝功能調整、血球、drug interaction、maximum label dose 或特殊藥物規則。請以 protocol、仿單、院內處方與臨床判斷為準。
公式與參考
Mosteller BSA = √(height(cm) × weight(kg) / 3600).
Carboplatin Calvert = target AUC × (GFR + 25).
IBW 採 Devine；Adjusted BW = IBW + 0.4 × (Actual BW − IBW)。
Mosteller, NEJM 1987 · ASCO obese dosing guideline update · Calvert et al., JCO 1989
